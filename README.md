1. Nama Aplikasi: FlashCardGo
- Aplikasi yang saya buat untuk menghafalkan materi dalam bahasa Jepang, Inggris, dan Indonesia berbentuk seperti kartu.


2. - Kartu untuk melihat soal di depan dan jawaban/penjelasan di belakang.
   - Materi dari bahasa Jepang, Inggris dan Indonesia yang berupa kartu, di depan ada soal dan belakangnya ada jawaban.
   - Pengaturan.
   - Mode gelap & terang.
   - Pilihan warna tema.
   - Piihan bahasa.
   - Memperbesar atau memperkecil ukuran teks kartu.

3. - Bahasa Pemrograman: Kotlin
   - UI Framework: Jetpack Compose & Material 3
   - Arsitektur: MVVM (Model-View-ViewModel)
   - Penyimpanan Lokal: Room Database (untuk data kartu) dan SharedPreferences (untuk menyimpan preferensi pengaturan).
   - Navigasi: Jetpack Navigation Compose


4. - Light Sensor (Sensor Cahaya): Digunakan untuk mendeteksi tingkat intensitas cahaya di sekitar perangkat secara real-time.
   - Accelerometer (Sensor Akselerometer): Digunakan untuk mendeteksi gerakan atau guncangan (shake) pada perangkat.
